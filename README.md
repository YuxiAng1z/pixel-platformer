# 🎮 像素风闯关游戏

一款基于 [Phaser 3](https://phaser.io/) 开发的马里奥风格 2D 横版闯关游戏，共三个主题关卡，支持直接在浏览器游玩，无需安装。

**🌐 在线试玩：[https://yuxiang1z.github.io/pixel-platformer/](https://yuxiang1z.github.io/pixel-platformer/)**

---

## 🗺️ 游戏内容

游戏共包含 **3 个主题关卡**，难度依次递增：

| 关卡 | 主题 | 敌人类型 | 通关奖励 |
|------|------|----------|----------|
| 第一关 | 🌲 森林 | 紫色带刺怪 | +1000 分 |
| 第二关 | 🏜️ 沙漠 | 橙色墨镜怪 | +1500 分 |
| 第三关 | 🌊 海洋 | 青色水母怪 | +2000 分 |

每个关卡都有：
- 跳跃平台与地面断层，需要精准跳跃才能通过
- 来回巡逻的敌人
- 关卡终点的**传送门**，到达即可过关
- 剩余生命加成（每条命 +500 分）

通关全部三关后，会触发彩带庆祝动画 🎉

---

## 🕹️ 操作方法

| 按键 | 功能 |
|------|------|
| `←` 方向键 | 向左移动 |
| `→` 方向键 | 向右移动 |
| `↑` 方向键 | 跳跃 |
| 短按 `↑` | 低跳 |
| 长按 `↑` | 高跳（变速跳跃） |

> 支持点击菜单中的 **开始游戏** 按钮，或按 `空格键` 快速开始。

---

## ⚔️ 战斗机制

- **踩踏击杀**：从敌人正上方跳下踩到头部，即可消灭敌人并弹跳
  - 森林怪：+100 分
  - 沙漠怪：+150 分
  - 海洋水母：+200 分
- **侧面碰撞**：碰到敌人侧面或正面 → 玩家死亡，消耗一条生命
- **坠落死亡**：掉出地图边界 → 同上

---

## ❤️ 生命与计分

- 初始 **3 条生命**，死亡后重启当前关卡（消灭的敌人不会复活）
- 生命耗尽 → 返回主菜单
- **最高分**自动保存到本地，每次进入主菜单可查看历史记录

---

## 🛠️ 技术栈

- **引擎**：[Phaser 3.80.1](https://phaser.io/)（CDN 引入，无需构建工具）
- **语言**：纯 HTML + 原生 JavaScript（无框架）
- **部署**：GitHub Pages（自动 CI/CD via GitHub Actions）

## 📁 项目结构

```
pixel-platformer/
├── index.html              # 游戏入口
└── js/
    ├── main.js             # Phaser 游戏配置
    ├── Player.js           # 玩家类（移动、跳跃、死亡）
    └── scenes/
        ├── MenuScene.js    # 主菜单
        ├── ForestLevel.js  # 第一关：森林
        ├── DesertLevel.js  # 第二关：沙漠
        ├── OceanLevel.js   # 第三关：海洋
        └── ScoreScene.js   # 关卡结算界面
```
