# 🎮 像素风闯关游戏 | Pixel Platformer

一款基于 **Phaser 3** 的马里奥风格 2D 横版闯关游戏，支持 PC 键盘和手机触屏双端操控。

**🌐 在线试玩：[https://yuxiang1z.github.io/pixel-platformer/](https://yuxiang1z.github.io/pixel-platformer/)**

---

## ✨ 游戏特色

- 🎨 **程序生成像素美术** — 所有角色、敌人、Boss 均由代码实时绘制
- 🎵 **程序化音频** — Web Audio API 生成背景音乐与音效，零外部文件
- 🌍 **四语言支持** — 简体中文 / 繁體中文 / English / 日本語
- 📱 **双端适配** — PC 键盘 + 手机虚拟摇杆，启动时自由选择
- ⏱️ **可选计时模式** — 在设置中开启，每关 90 秒倒计时挑战
- 🦑 **Boss 战** — 第三关后进入深海章鱼 Boss 战，三阶段难度递增

## 🕹️ 操作方式

### 💻 PC 键盘

| 按键 | 功能 |
|------|------|
| `←` `→` 或 `A` `D` | 左右移动 |
| `↑` 或 `W` 或 `Space` | 跳跃（按一次起跳） |
| 空中再按一次跳跃键 | **二段跳** |
| 短按 vs 长按跳跃键 | 低跳 / 高跳（变速跳跃） |

### 📱 手机触屏

| 控件 | 功能 |
|------|------|
| 左侧虚拟摇杆 | 左右移动（拖拽） |
| 右侧跳跃按钮 | 跳跃 / 二段跳 |

> 在主菜单可随时切换 PC / 手机模式。

## ⚔️ 战斗机制

- **踩踏击杀**：从正上方踩到敌人头部 → 消灭敌人 + 弹跳
  - 森林怪 +100 分 · 沙漠怪 +150 分 · 水母 +200 分
- **Boss 踩踏**：踩一次 Boss -1 HP（共 10 HP），踩中后弹起 +300 分
- **侧面/正面碰撞** → 玩家死亡，扣一条命
- **坠崖 / 踩尖刺** → 同上
- **Boss 战死亡** → 原地重试，**不扣生命**

---

## 🦑 Boss 战详解

| 阶段 | HP 范围 | 行为 |
|------|---------|------|
| Phase I | 10 → 7 | 左右移动 + 每 1.8s 发射 1 颗墨弹 |
| Phase II | 6 → 4 | 加速移动 + 每 1.1s 发射 2 颗墨弹 |
| Phase III | 3 → 0 | 高速移动 + 每 0.7s 发射 3 颗弹幕 + 触手横扫 |

---

## ❤️ 生命与计分

- 初始 **3 条生命**，死亡后重启当前关卡（已消灭敌人不复活）
- 生命耗尽 → 返回主菜单
- **加分项**：踩怪 · 金币（+50/枚）· 通关奖励 · 剩余生命（+500/条）· 剩余时间（计时模式 +10/秒）
- **最高分**自动保存到本地 `localStorage`

---

## ⚙️ 设置选项

在主菜单点击 **⚙ 设置**，或游戏中点 **⏸ 暂停** → **⚙ 设置**：

| 选项 | 说明 |
|------|------|
| 计时模式 | 开启后每关 90 秒倒计时，超时扣一条命 |
| 语言 | 简中 / 繁中 / EN / 日 |
| BGM | 背景音乐开关 |

暂停菜单还支持：继续游戏 · 重新开始 · 返回主菜单。

## 📁 项目结构

```
pixel-platformer/
├── index.html                  # 入口
├── assets/sprites/             # AI 生成的像素精灵图（备用）
├── js/
│   ├── main.js                 # Phaser 配置 + 场景注册
│   ├── i18n.js                 # 四语言国际化系统
│   ├── AudioManager.js         # Web Audio 音乐/音效管理器
│   ├── LevelMixin.js           # 关卡通用逻辑（HUD/计时/金币/暂停）
│   ├── Player.js               # 玩家类（二段跳/WASD/手机接口）
│   ├── MobileControls.js       # 虚拟摇杆 + 跳跃按钮
│   └── scenes/
│       ├── BootScene.js        # 启动 + 程序生成所有纹理
│       ├── PlatformSelectScene.js  # PC/手机选择
│       ├── MenuScene.js        # 主菜单 + 设置面板
│       ├── ForestLevel.js      # 第一关：森林
│       ├── DesertLevel.js      # 第二关：沙漠
│       ├── OceanLevel.js       # 第三关：海洋
│       ├── BossScene.js        # Boss 战：深海章鱼
│       └── ScoreScene.js       # 关卡结算
└── .github/workflows/
    └── deploy.yml              # GitHub Pages 自动部署
```
